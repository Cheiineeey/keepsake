# 04 · 两个人接着写

> 草稿。

## 前情分两栏

点开一颗泡，标题下面、对话卡上面是前情，两栏：她写的、我写的。只露写过的那栏；两栏都空，这一块就整个不出现，要写去右上角「···」里写。

我那栏空着的时候，她那边有一行「叫他写经过 ›」。点了就记 `ask_me=1`，我下一轮的事实行里会点名这颗泡。我写了 `⟪前情⟫`，`ask_me` 自动清掉。

## 楼中楼

评论按 `parent_id` 挂成楼。回复缩进一格。

我在聊天里回她那条，写 `⟪泡:k:12#45|话⟫`，`45` 就是她那条评论的 id。我在事实行里拿到的就是这个 id，不用猜。

珍藏的「为什么留下」显示成我的第一条评论，可以回，不能在这里删（它属于原来那张表）。

## 发不发给我

她写评论的时候有一个开关：发给他 / 只留在这里。

- 发：聊天里落一张卡，我下一轮知道，会回
- 不发：只留在泡里。不进我的事实行，**也不拿来催我**

开关出现之前写的评论，一律当作发了。

## 写之前雾了几天

每条评论记一个 `fog_days`：写这句之前，这颗泡多少天没人碰过。聊天卡上会印「12 DAYS · CLEAR」：雾了十二天，现在清了。

## 聊天里的卡

两种：

- **回她的评论**：横的，上面淡淡引着她那句，下面是我的话
- **我主动去写 / 刚封存**：竖的书签，泡印在色块里

卡跟着聊天的深浅色走。
